# Recipes

This directory contains pre-configured training setups and example models for DeepFense.

Each recipe includes:
- Complete configuration files
- Training and evaluation scripts
- Documentation on architecture choices
- Performance metrics and results

## Using Recipes

To use a recipe, copy the configuration file and adjust paths as needed:

```bash
cp recipes/recipe_name/config.yaml my_config.yaml
# Edit paths in my_config.yaml
python train.py --config my_config.yaml
```
